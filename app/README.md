# OpenRoutine (Flutter app)

The Flutter client for [OpenRoutine](../README.md). See the root README for the project overview and [`docs/SPEC.md`](../docs/SPEC.md) for the full technical spec.

## Dev setup

Requires Flutter 3.41.4 (see the "Dependency notes" comment at the top of `pubspec.yaml` for why several deps are pinned below latest).

```
flutter pub get
flutter gen-l10n
flutter analyze
flutter test
```

See [`CONTRIBUTING.md`](../CONTRIBUTING.md) for project-wide conventions.
